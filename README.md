# Store Inventory Management System
A desktop application built with python and Tkinter for managing inventory and rentals in a catering and event company

# Features
- Add and manage stock items
- Issue items
- Return items
- Delete items
- Customer tracking
- Activity logs
- Transaction records history
- Excel sheet for reports

# Technologies
- Python
- Tkinter
- JSON
- Openpxyxl

# How to run
1. Clone the repository
```bash
2. git clone https://github.com/justify-code/store_inventory_management_system.git
3. cd store_inventory_management_system
4. python main.py 
```
